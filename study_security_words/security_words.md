# 보안용어

## 정보보호 기초

- 정보자산 : 조직이 보유한 데이터, 시스템 네트워크, 문서, 소프트웨어 등 보호해야 할 모든 가치 있는 자산
- 정보보호 : 정보의 기밀성, 무결서, 가용성을 유지하여 정보 자산을 안전하게 보호하는 활동

  - 기밀성 : 인가되지 않은 사람이 정보에 접근하거나 열람하지 못하도록 하는 보안원칙
  - 무결성 : 정보가 인가되지 않은 방법으로 변경, 삭제, 훼손되지 않고 정확성을 유지하는 보안 원칙
  - 가용성 : 권한이 있는 사용자가 필요할 때 언제든지 정보와 시스템을 사용할 수 있도록 하는 보안 원칙
- 인증 : 사용자가 주장하는 신원이 실제 본인인지 확인하는 절차
- 인가 : 인증된 사용자에게 업무 수행에 필요한 권한을 부여하는 과정
- 접근제어 : 사용자나시스템의 자원 접근을 허용하거나 제한하는 보안 기술 및 정책
- 암호화 : 정보를 인가된 사용자만 이해할 수 있도록 특정 알고리즘을이요해 변환하는 기술
- 다중인증 : 비밀번호 외에 OTP, 생체인증, 인증앱 등 두 가지 이상의 인증 수단을 사용하여 본인을 확인하는 방법
- 보안정책 : 조직의 정보 자산을 보호하기 위해 수립한 보안 규정, 절차 및 관리기준
- 취약점 : 보안 통제의 부재, 오류, 설정 실수 등으로 인해 공격자가 시스템에 접근하거나 악용할 수 있는약점
- 위협 : 정보자산에 피해를 줄 수 있는 잠재적인 사건이나 행위
- 위험 : 위협이 취약점을 이용하여 실제 피해가 발생할 가능성과 영향의 정도

## 보안 위협

- 해킹 : 컴퓨터의 취약한 보안망에 불법적으로 접근하거나 정보 시스템에 유해한 영향을 끼치는 행위
- 악성코드 : 제작자가 의도적으로 사용자에게 피해를 주고자 만든 모든 악의적 목적을 가진 프로그램 및 매크로, 스			    크립트 등 컴퓨터 상에서 작동하는 모든 실행 가능한 형태
- 랜섬웨어 : 몸값(Ransom)+낚는다(Fishing)의 합성어, 피해자를 기망 또는 협박 하여 개인정보 및 금융거래 정보를 요구하거나 피해자의 금전을 이체하도록 하는 수법
- 스미싱 : 문자 메세지(SMS)+Fishing의 합성어, 문자메세지 내 악성 링크를 클릭하도록 유도하는 수법
- 스피어 피싱 : 특정개인이나 기업을 목표로 신뢰할 수 있는 사람이나 기관을 사칭하여 개인정보나 중요 정보를 탈취하는 맞춤형 피싱 공격
- 크리덴셜 스터핑 : 사용자 계정을 탈취해 공격하는 유형 중 하나로, 다른 곳에서 유출된 아이디와 비밀번호 등의 로그인 정보를 다른 웹사이트나 앱에 무작위로 대입해 로그인이 이뤄지면 타인의 정보를 유출시키는 수법
- 딥페이크 : 인공지능(AI)을 이용해 사람의 얼굴, 음성, 영상을 실제처럼 합성하는 기술로, 가짜 영상이나 음성을 만들어 사기, 허위정보 유포등에 악용될 수 있는 기법
- 사회공학적 공격 : 보안학적 측면에서 기술적인 방법이 아닌 사람들 간의 기본적인 신뢰를 기반으로 사람을 속여 비밀정보를 획득하는 기법
- 지능형 지속 위협(APT) : 조직이나 기업을 표적으로 정한 뒤 장기간에 걸쳐 다양한 수단을 총동원 하는 지능적 해킹 방식
- DDos공격 : 다수의 컴퓨터를 이용해 특정 서버나웹사이트에 대량의 접속 요청을 보내 정상적인 서비스 제공을 어렵게 만드는 공격 기법

## 개인정보보호

- 개인정보 : 개인을 알아볼 수 있는 정보로서 이름, 연락처, 영상 등 단독또는 다른정보와 결합하여 개인을 식별할 수 있는 정보
- 고유식별정보 : 주민등록번호, 여권번호, 운전면허번호, 외국인등록번호 등 개인을 고유하게 식별하기 위해 부여된 정보
- 민감정보 : 사상, 신념, 건강정보, 유전자정보, 생체인식정보 등 유출시 사생활 침해 우려가 큰 개인정보
- 가명정보 : 이름 등 식별정보를 삭제하거나 다름 값으로 대체하여 특정 개인을 바로 알아볼 수 없도록 처리한 개인정보           ex) 홍길동 ->김**
- 익명정보 : 시간, 비용, 기술 등을 합리적으로 고려하도록 다른 정보와 결합하여 개인을 식별할 수 없도록 처리한 정보
- 정보주체 : 개인정보의 주인이 되는 사람으로, 자신의 개인정보에 대한 권리를 가진 개인
- 개인정보처리자 : 업무 목적으로 개인정보를 수집, 이용, 보관, 제공하는 공공기관, 단체 또는 개인
- 개인정보 동의 : 개인정보 수집, 이용, 제공 목적과 내용을 확인한 후 정보주체가 이를 허락하는 행위
- 개인정보 처리방침 : 기업이나 기관이 개인정보를 어떻게 수집, 이용, 보관, 파기하는지 공개한 정책문서
- 개인정보 파기 : 개인정보 보유기간이 종료되거나 처리 목적이달성된 후 복구할 수 없도록 삭제하는 행위
- 개인정보 노출 : 개인정보가 실수나 설정 오류 등으로 인터넷이나 외부에 공개되어 누구나 볼 수 있는 상태
- 개인정보 유출 : 개인정보가 해킹, 내부자 실수, 악성코드 등에 의해 권한 없는 사람에게 전달되거나 된 상태
- 안전성 확보 조치 기준 : 개인정보 분실, 도난, 유출 등을 방지하기 위해 개인정보처리자가 수행해야 하는 기술적, 관리적, 물리적 보호조치 기준

## 데이터 보안기술

- 정보유출방지(DLP) : 사내 네트워크, 이메일,USB 등 데이터가 나가는 모든 경로를 감시하여 중요 정보의 외부 유출을 차단하는 기술
- 개인정보 보호 기술 : 암호화, 접근 제어 등 기술적 수단을 활용하여 데이터베이스(DB) 내 개인정보의 유출과 오남용을 막는 솔루션
- 개인정보 비식별화 : 개인을 식별할 수 있는 요소를 삭제하거나 대체하여, 프라이버시는 지키면서 빅데이터로 활용할 수 있게 만드는 기술
- 이미지 글자 인식(OCR) & 의미분석(NER) : OCR(Optical Character Recognition)로 글자를 추출하고 NER(Named Entity Recognition)로 개인정보를 식별하여 민감정보를 자동 탐지하는 기술
- 합성데이터 : 실제 데이터의 유출 위험을 업애기 위해, AI가 원본의 통계적 특성만 모방하여 새로 생성해낸 안전한 가상 데이터
- 데이터 암호화 : 정보를 허가된 사람(암호 키 소유자)만 읽을 수 있도록 알아볼 수 없는 암호문 형태로 변환하는 원천 방어 기술
- 문서 암호화(DRM) : (Digital Rights Management) : 기업 내부 문서를 생성 시점부터 암호화하여 열람 복사, 인쇄 등 사용 권한을 세부적으로 통제하는 기술
- 문서 중앙화 : 개인 PC저장을 금지하고 모든 업무 문서를 회사의 중앙 서버에만 저장하여 통합 관리하는 기술
- 문서 위변조 방지 & 워터마크 : 전자문서의 무결성을 증명하는 위변조 방지 기술과 최초 유출자 추적 및 무단 복제를 막기 위해 표식을 남기는 워터마크 기술
- 백업 : 랜섬웨어, 데이터파손 등 만약의 사태에 대비해 원본 데이터를 안전한 별도 저장소에 복사해 두는 필수작업
- 복구 : 데이터 유실 사고 발생 시, 미리 준비한 백업본을 이용해 시스템을 사고 이전의 정상 상태로 되살리는 작업

## 네트워크보안

- TCP/IP : 인터넷에서 데이터를 주고 받기 위해 사용하는 대표적인 통신 규약, 데이터 전송 규칙을 정의
- IP주소 : 인터넷에 연결된 장치를 식별하기 위해 사용하는 고유한 주소, 네트워크에서 목적지를 식별하기 위해 사용
- 포트(Port) : 하나의 컴퓨터에서 웹, 이메일 등 다양한 서비스를 구분하기 위해 사용하는 논리적인 통신번호, 같은 IP주소에서도 포트번호를 통해 서로 다른 서비스에 연결할 수 있음
- 패킷(Packet) : 네트워크에서 데이터를 전송하기 위해 일정한 크기로 나누어 전달하는 정보의 단위
- DNS(Domain Name System) : 사람이 이해하기 쉬운 도메인 이름을 컴퓨터가 이해하는 IP주소로 변환해 주는 시스템
- 스위치(Switch) : 동일한 네트워크에 연결된 장치 간 데이터를 올바른 목적지로 전달하는 네트워크 장비
- 라우터 : 서로 다른 네트워크를연결하고 데이터가 목적지까지 이동할 최적의 경로를 결정하는 장비
- VPN : 공용 인터넷 환경에서도 안전하게 내부망에 접속할 수 있도록 통신을 암호화하는 기술
- 스니핑 : 네트워크를 통해 전송되는 데이터를 몰래 가로채어 내용을 확인하는 도청 공격 기법, 계정정보나 개인정보 탈취에 악욕될 수 있는 위협
- 스푸핑 : IP주소, 이메일주소, 웹사이트 등을 위조하여 정상 사용자나 시스템인 것 처럼 속이는 공격기법
- IDS : 네트워크에서 발생하는 비정상적인 행위나 공격 시도를 탐지하여 관리자에게 알려주는 보안 시스템
- IPS : 악성 트래픽이나 공격을 탐지한 후 자동으로 차단하여 피해를 예방하는 보안 시스템

## 생성형 AI보안

- 생성형 AI : 사람의 요청에 따라 텍스트, 이미지, 영상, 코드 등을 새롭게 생성하는 인공지능 기술
- LLM : 방대한 데이터를 학습하여 사람처럼 언어를 이해하고 생성하는 대규모 언어모델
- 프롬프트(Prompt) : 생성형 AI에게 원하는 작업을 요청하기 위해 입력하는 질문이나 명령어
- RAG : 외부 문서나 데이터베이스를 겁색하여 AI답변의 정확성을 높이는 기술
- AI에이전트 : 주어진 목표를 달성하기 위해 스스로 판단하고 여러 작업을 수행하는 인공지능 시스템
- AI거버넌스 : AI의 안전성, 신뢰성, 윤리성을 확보하기 위한 정책과 관리 체계
- 멀티모달 : 텍스트, 이미지, 음성, 영상 등 다양한 형태의 정보를 함께 이해하고 처리하는 AI기술
- AI환각 : 실제 사실과 다른 내용을 AI가 사실처럼 생성하는 현상
- 프롬프트 인젝션 : 악의적인 입력을 통해 AI의 동작을 조작하거나 보안 정책을 우회하는 공격 기법
- 프롬프트 리크 : 생성형 AI에 숨겨진 지침이나 내부 정보를 질문을 통해알아내려는 공격 기법, 기업의 기밀정보 유출로 이어질 수 있는 보안 위협
- 탈옥 : AI에 설정된 제한이나 안전장치를 우회하여 금지된 답변을 유도하는 기법
- 데이터 포이즈닝 : 학습 데이터에 악의적인 정보를 삽입하여 AI의 결과를 왜곡하는 공격 기법
- 모델 스틸링 : AI모델의 기능이나 학습 결과를 분석하여 복제하려는 공격 기법

## 클라우드 보안

- 클라우드 컴퓨팅 : 인터넷을 통해 서버, 저장공간 소프트 웨어 등을 필요한만큼 할당 해서 사용하는 컴퓨팅 방식
- SaaS(Software as a Service) : 소프트웨어를 설치하지 않고 인터넷을 통해 바로 사용하는 클라우드 서비스 모델
- PaaS(Platform as a Service) : 애플리케이션개발과 운영에 필요한 플랫폼 환경을 제공하는 클라우드 서비스 모델
- IaaS(Infrastructure as a Service) : 서버, 스토리지, 네트워크, 등 IT인프라를 제공하는 클라우드 서비스 모델
- VPC(Virtual Private Cloud) : 클라우드 환경에서 기업 전용으로 구성하는 가상의 네트워크 공간
- IAM(Identity and Access Management) : 사용자와 시스템의 접근 권한을 관리하는 클라우드 보안 체계
- 책임공유모델(Shared Responsibility Model) : 클라우드 서비스 제공자와 고객이 각자의 역할에 따라 보안 책임을 나누어 수행하는 보안 관리 모델
- 컨테이너 : 애플리케이션과 실행 환경을 하나로 묶어 어디서나 동일하게 실행할 수 있도록 하는 기술
- 쿠버네티스 : 다수의 컨테이너를 자동으로 배포하고 운영, 관리하는 오픈소스 플랫폼
- CSPM(Cloud Security Posture Management) : 클라우드 환경의 보안 설정 오류와 위험 요소를 점검, 관리하는 기술
- 제로 트러스트 : 아무도 기본적으로 신뢰하지 않고 지속적으로 검증하는 보안 모델
- DevSecOops : 소프트웨어 개발 단계부터 보안을 함께 적용하여 안전한 서비스 구축하는 개발 문화 및 방법론

## 보안관제,침해대응

- SOC(Security Operations Center) : 보안 이벤트를 모니터링하고 침해사고를 탐지, 분석, 대응하는 보안관제 조직
- 로그(Log) : 시스템, 서버, 네트워크 등에서 발생한 활동 내역을 기록한 데이터
- 이벤트(Event) : 시스템이나 네트워크에서 발생하는 모든 활동 또는 변화
- 알림(Alert) : 보안 위협이나 이상행위가 탐지되었을 때 관리자에게 전달되는 경고 정보
- IOC(Indicator of Compromise) : 악성코드 감염, 해킹 등 침해사고가 발생했음을 나타내는 흔적이나 지표
- 위협 인텔리전스 : 사이버 공격자, 공격기법, 악성코드 등에 대한 정보를 수집, 분석한 위협 정보
- 위협 헌팅 : 자동 탐지 시스템이 발견하지 못한 위협을 능동적으로 찾아내는 보안 활동
- 디지털 포렌식 : 사고 발생 후 디지털 증거를 수집, 분석하여 원인과공격 경로를 조사하는 기술
- SIEM(SecurityInformation and Event Management) : 다양한 시스템의 로그를 수집 분석하여 보안 위협을 탐지하는 통합 보안 관리 시스템
- EDR(Endpoint Detection & Response) : PC와 서버 등 단말에서 발생하는 보안 위협을 탐지하고 대응하는 보안 솔루션
- XDR(Extended Detection & Response) : 단말, 네트워크, 클라우드 등 다양한 영역의 보안 정보를 통합 분석하는 보안 플랫폼
- SOAR(Security Orchestration, Automation and Response) : 보안위협 탐지 이후 분석, 대응 조치과정을 자동화하여 보안 업무의 효율성을 높이는 보안 운영 플랫폼
- 침해사고 대응 : 보안 사고 발생 시 피해를 최소화하고 정상 상태로 복구하기 위한 대응 절차

## 웹,애플리케이션 보안

- 웹 애플리케이션 : 웹브라우저를 통해 사용하는 소프트웨어로, 인터넷 뱅킹이나 쇼핑몰 등이 대표적인 예
- WAS(Web Application Server) : 웹서버의 요청을 받아 로그인, 주문처리, 데이터조회등동적 기능을 수행하는 서버
- 방화벽 : 허가되지 않은 접근을 차단하고 허용된 통신만 통과시키는 네트워크보안 기술
- WAF(웹방화벽) : 웹 서비스 앞단에서 수상한 요청을 탐지하고 차단하는 웹 전용 방화벽
- API(Application Programming Interface) : 시스템 간 데이터를 주고받기 위한 연결 인터페이스
- 쿠키(Cookie) : 웹사이트가 사용자정보를 저장하기 위해 사용하는 데이터 파일
- 세션(Session) : 사용자의 로그인 상태와 활동 정보를 관리하는 기술
- JWT(JSON Web Token) : 사용자 인증 정보를 전달하기 위해 사용하는 토큰 기반 기술
- SQL Injection : 악성 SQL구문을 이용해 데이터 베이스를 공격하는 기법
- XSS(Cross-Site Scripting) : 웹페이지에 악성 스크립트를삽입하는 공격 기법
- CSRF(Cross_Site Request Forgery) : 사용자의 권한을 악용하여 의도하지 않은 요청을 수행하게 하는 공격 기법
- SSRF(Sever_Side Request Forgery) : 서버가 내부 시스템에요청을 보내도록 악용하는 기법
- 파일 업로드 취약점(File Upload Vulnerability) : 악성 파일 업로드를 통해 서버를 공격하는 취약점
- OWASP Top10 : 가장 위험하고 빈번하게 발생하는 웹 보안 취약점 목록
- Secure Coding(시큐어 코딩) : 개발 단계에서 보안 취약점을 예방하기 위한 안전한 소프트웨어 개발 방법
